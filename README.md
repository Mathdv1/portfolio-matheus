# Portfólio do Matheus Souza — versão Aurora

Portfólio pessoal em HTML, CSS e JavaScript puros (sem dependências), compatível com a CSP do `vercel.json`.

## Recursos

- pré-carregamento em formato de terminal (aparece uma vez por sessão; clique para pular);
- fundo vivo: aurora animada, grade e partículas conectadas que reagem ao mouse;
- 4 paletas de cor (Aurora, Neon, Sunset, Oceano), salvas no navegador;
- nome com brilho animado e cargos digitados em loop;
- foto com moldura de gradiente girando, inclinação 3D e órbita de tecnologias;
- marquee infinito de tecnologias, terminal interativo e contadores;
- cartões com spotlight que segue o mouse e projetos com inclinação 3D;
- botões magnéticos, cursor com brilho, barra de progresso de rolagem;
- Discord copia `mathshenq`; Instagram, GitHub e e-mail configurados;
- respeita `prefers-reduced-motion`; layout responsivo;
- easter egg: código Konami (↑ ↑ ↓ ↓ ← → ← → B A).
